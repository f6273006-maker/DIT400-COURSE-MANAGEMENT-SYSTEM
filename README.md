## 🧠 Project Overview
This is a console-based Course Management System built in **C++** using **arrays and file I/O only**, then converted to **Java**. It allows users to register, log in, and manage course records.

---

## 🛠️ Features

### 🔐 User Authentication
- Register new users
- Login using credentials stored in `users.txt`

### 📚 Course Operations
- Add new course (with unique ID)
- Delete course by ID
- Search course by ID or title keyword
- Update course title or credit hours
- List all courses

### 📁 Data Storage
- `users.txt`: stores usernames and passwords
- `courses.txt`: stores courseId, title, and creditHours
